TINYUI BASIC TERMINAL UI FOR IDIOTS (like me)
- DEPENDS ON NCURSES. (or wraps ncurses, wtf)
- HAS ONLY 3 LAYERS AS ELEMENTS, MAINLY:
  ~ ENVIRONMENT (env) LAYER
  ~ PLANE (plane) LAYER
  ~ DIALOGUE (dialogue) LAYER
  
  ENVIRONMENT ELEMENT:
    STORES PLANES (uses vec2, at tinyui/types.h)
    METHOD OF KEEPING TRACK OF THOSE PLANES ARE VIA AN ARRAY
    ARRAY + INDEX
    
  PLANE ELEMENT:
    STORES DIALOGUE STUFFS (texts)
    HAS SIZE AND POS, IF YOU WANNA TREAT THE PLANE AS A WINDOW OR SMTH
    AND HOLDS MEM ADDRESS TO ITS PARENT ENV (env* currentEnv = root_plane->pEnv)
    
  DIALOGUE ELEMENT:
    STORES TEXT (for buffer size, see tinyui/types.h, #DEFINE T_MAX_DIALOGUE_TEXT_BUFFER)
    STORES POSITION (using the position of the parent plane as its origin)
    STORES THE PARENT PLANE (plane* dialogueParentPlane = thisDialogue->pPlane)
